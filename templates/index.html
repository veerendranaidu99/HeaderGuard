How HeaderGuard evaluates a website

Transparent, rule-based checks designed for learning and demonstration.

01 / Collection

The Flask backend sends a single HTTPS GET request with certificate verification enabled. Redirects are not followed automatically.

02 / Analysis

Nine response headers are checked using a weighted model. The score measures presence, not the correctness of each policy.

03 / Reporting

Findings include status, severity, observed value, purpose and remediation guidance. Scan records are stored in SQLite.

04 / Limitations

This is not a penetration test, vulnerability scanner or compliance certification. Some headers are appropriate only for particular applications.

Scoring model

Content-Security-Policy 25; HSTS 20; X-Content-Type-Options 10; Referrer-Policy 10; Permissions-Policy 10; X-Frame-Options 10; COOP 5; CORP 5; COEP 5. Total: 100 points.

Reference: OWASP HTTP Headers Cheat Sheet.
